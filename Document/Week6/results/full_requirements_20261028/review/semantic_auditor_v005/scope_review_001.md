# v5 independent reviewer adaptation

Original v4-era auditor/test bytes are preserved in the adjacent `semantic_auditor_v004_pre_v5` directory. This snapshot follows 65 actual offline CPU passes in 22.76 seconds, pytest/Ruff exit0 and 13 unchanged selected pins. It is not a real model/GUI success or a final full-suite result.

The original 50 safety cases remain. Fifteen new cases cover reserved unresolved markers before any observation/HTTP, exact raw caller membership/polarity before normalization, multiple final predicates becoming true simultaneously without a second valid stage, runtime evidence leaking into intent input, and independently bound snapshot pixels/runtime archives. The original failed-goal/no-final-rescue test now places the complete caller final only in a later revision observation, after the fixed goal post-frame failed; a trusted verifier confirms that later final is true and the original goal still remains failed. This preserves the tested safety path under the caller-predicate subset rule.

The read-only auditor binds the preflight, exact signed predicate pools, the schema in both readable system text and transport response_format, raw native predicates before parsing, native/validated/compiled mapping, logical-only completion/failure input, complete original archived snapshot/runtime context, byte-identical copied pixels, shared accounting, steps/plans, fresh goal/final frames and original owner exit. Current source pins must match the actually selected live run.

Independent fixture review still requires the complete project→theme→review→commit event order and the preset rejection count; every event must belong to exactly one successful owned Sky receipt and different transitions cannot share one receipt. Completed stages need independently attributed transitions. Natural-language meaning is not universally proven by literal text matching: the actual native instructions and their per-stage transitions must also be read for semantic alignment. No v5 live positive was available when this review was recorded.

Live transport logging preserves actual dispatch counts, saved pre-encoding messages and original provider replies. It does not preserve raw wire request bodies; offline SDK body tests must not be described as a byte audit of a live wire request. High-level intent input omits the snapshot; retaining its archive is a separate fact.
