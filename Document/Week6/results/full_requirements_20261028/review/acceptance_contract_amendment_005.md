# Week6 预测中间后置条件修订 005

登记时间：2026-10-28 09:37 UTC。决定来源：Root 在 v5 normal007、normal008
真实非接受结果保存后，明确授权 v6 设计。本文件先于 v6 真实窗口验收，不证明
实现、测试、模型方案或发布已经通过。

原合同、修订 002 至 004、全部原始模型响应、失败收据、源码快照和报告均保留。
本修订明确替代修订 004 的“阶段文字只能来自 caller final 同极性池”限制；这是
中间判据来源和表达范围的改变，不能描述为全部验收门槛都没有改变。

## 改变的来源约束

高层继续采用 caller_intent_only：完整原始 caller 意图与不可变的最终文字规则
进入模型；当前窗口/OCR/几何/截图只归档并用于执行前范围和状态检查，不发送
给高层。低层每次动作规划继续接收该次真实截图。

v6 允许模型原生提出 caller final 之外的中间 expect_text / forbid_text。
这些文字是“不可信的模型预测”，并非调用方承诺、观察到的事实或已通过的后态。
传输 schema 和模型可读 schema 仍一致；不再用 final-pool enum 限制来源。

本地须严格检查原生对象字段、必需数组、列表/字符串原始类型、非空串、长度、
条数、目标去重及完整 native → validated → compiled 映射。不得静默 strip、
纠错、替换预测文字或程序合并目标来制造可接受方案。原始 instruction 与任何
有声明的 instruction 规范化另列；阶段文字在编译和验证中逐字保留。

仅因 final-pool 设计而引入的“至少两个 caller 文字谓词”以及“caller 单条文字
不超过阶段预测上限”入口限制随之撤销。初始模型仍须原生给出至少两个不同、
有顺序、可解释的语义目标；不能本地凑数、强制 ready 或给模型 fixture 答案。
明确保留标记的 0 HTTP 前置拒绝和真正 caller 正反文字矛盾的拒绝继续保留。
保留标记检查不是完整的自然语言歧义识别。

v5 任务不是逻辑上无解：模型本可合并具有相同完整检查的相关未完成操作，组成
不同的后续目标。007/008 的真实模型没有生成该受限协议可接受的序列。v6 扩大
表达范围，不能把这两次实测失败写成 v5 数学不可能的证明。

## 预测不构成完成证据

每个目标的 instruction、全部文字判据和执行顺序必须在该目标首个输入前固定。
可信 before 帧上整组判据须明确未满足；已满足、空屏、不稳定窗口、范围或证据
不清均不得作为新的进展信用。不能在观察到结果后改写目标或判据。

目标完成仍必须同时具有所属窗口内真实、已确认、非 dry-run 的输入，随后可信
新帧上的固定阶段检查通过，以及另一张新帧复核。各阶段完成台账、已确认阶段
不重放、unknown/取消/超时/证据错误不救回、共享动作/规划/实际 HTTP/期限预算
和单步动作规划会计都保持原严格门槛。

新出现的下一阶段 caption 可以是预测见证，不能一概禁止 caption。但既有文字
或当前动作按钮本身不能单独获得完成信用。before 整组未满足与 after 文本通过
仍不足以普遍证明目标语义和输入因果；真实验收必须人工核对原生各目标 instruction
与独立应用事件，确认所有要求操作都发生、顺序正确，并且每事件对应唯一的真实
Sky 输入回执。仅 predicates/status/ready 或 callback 声明均不够。

调用方 final 原文和检查独立不变；所有目标完成后另取可信新帧检查完整 final。
失败阶段不得因 final 可见而追认。动作级模型 expected_result 的 failed 或
inconclusive 按原件单列，不改写为 passed，也不据此扣成模型质量零分。

## 已知边界和可证伪条件

未知未来标签可能根本不存在、拼写不符或不是合适阶段边界；必须保守失败或按
既有受限修订流程处理，不能事后改检查、填缺失观察或利用 fixture 隐藏状态。

当前普通 Verifier 使用 casefold 子串匹配，例如 Saved 可能命中 Not saved。
本轮不悄改 legacy、caller final 或全局匹配算法；此限制必须保留在报告和审计中。
原生检查宜表达具体状态上下文，但提示词建议不能替代硬证明。若任务依赖精确
元素相等、否定语义或控件角色，应另行定义和验证专用契约，不能声称本轮已经
解决。既有完整 caller 正反冲突保护不能推论检测了所有自然语言否定。

R1/R2 新源码真实窗口矩阵、首次 UI 拒绝恢复、独立事件和唯一回执、真实 owner
子退出码、源码前后绑定、日志闭合、最终全量回归及报告/发布检查不变。新 v6
结果必须绑定新源码；v5 full003、旧 rolling 成功或诊断模型方案不能替代。

最终只能据实际验收声明受控任务范围内的结果，不扩展为任意应用、任意未来
页面、完整语义幂等、全部自然语言歧义或纯图形高层理解都已得到证明。
